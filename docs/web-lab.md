# Веб-лаборатория

Актуальный файл — `audio_codec_lab_v12_vorbis_opus.html`. Он открывает аудио, поддерживаемое браузером, переводит его в mono, выполняет анализ, кодирование, обратное декодирование и строит сравнение исходной и восстановленной формы сигнала.

## Режимы

### LFA-3

Аддитивные синусоидальные дорожки, локальные частотные палитры и полосовой шум. Формат предназначен для экспериментов с параметрическим представлением произвольного звука.

### LPC1

Talkie-подобный контрольный речевой кодек. Нужен для прямого сравнения с улучшенным вариантом.

### LPC2 Improved

LSF, улучшенный pitch-анализ, смешанное возбуждение, интерполяция по подкадрам и декодерские фильтры. Файлы имеют расширение `.lp2` и совместимы с Arduino-декодером из проекта.

### Ogg Vorbis

- VBR quality от −1 до 10;
- частота дискретизации до 48 кГц;
- настоящий контейнер `.ogg`;
- обратное декодирование и расчёт фактического битрейта;
- кодирование через `wasm-media-encoders` 0.7.0.

При первом использовании нужен интернет для загрузки WASM-модуля.

### Opus

- 6–128 кбит/с;
- VBR или CBR;
- назначения auto, voice, music;
- профили VoIP, Audio, Low delay;
- сложность 0–10;
- внутренний режим 48 кГц, кадры 20 мс.

Сначала используется `AudioEncoder` WebCodecs. При успехе страница формирует Ogg Opus с `OpusHead`, `OpusTags`, granule position и CRC страниц. Если Opus в WebCodecs недоступен, используется `MediaRecorder`: предпочтительно Ogg Opus, иначе WebM Opus.

## Открываемые файлы

```text
.lfa
.lpc
.lp2
.ogg
.opus
.webm
```

Для стандартных кодеков показываются размер потока, контейнер, используемый энкодер, заданное качество или битрейт, фактический итоговый битрейт и степень сжатия относительно mono PCM16.

## Ограничения проверки

Разработка в исходном чате включала синтаксическую проверку JavaScript, проверку CRC Ogg, переключение экспериментальных маршрутов и реальное кодирование Opus через MediaRecorder. Vorbis не запускался в тестовой среде из-за запрета внешней загрузки; интеграция выполнена по опубликованному API библиотеки. Arduino-код синтаксически проверялся и декодировал искусственный LPC2-поток, но физическая ATmega328P в исходной среде не тестировалась.
