# Хронология разработки

Эта страница фиксирует решения из исходного обсуждения и связывает их с сохранёнными файлами.

| Версия | Основное изменение |
| --- | --- |
| LFA-1 | Первый автономный FFT-энкодер и аддитивный декодер с логарифмической сеткой |
| v2 | Исправление стыковки сегментов, плавные огибающие и непрерывность фазы |
| v3 | Независимый шаг кадров 20 мс при более длинном FFT-окне |
| v4 / LFA-2 | Палитры частот суперкадра и 4-битные локальные индексы |
| v5 / LFA-3 | Отдельный полосовой шумовой слой |
| v6 | Выпадающий список LFA-3 и LPC1/Talkie-подобного режима |
| v7 | DC removal и пиковая нормализация входа |
| v8 | Сбалансированное LPC-возбуждение и DC-block |
| v9 | Более широкополосное возбуждение, яркость и уменьшение «бубнения» |
| v10 | Дробное смещение логарифмической сетки LFA-декодера |
| v11 | Независимый LPC2 Improved с LSF и четырьмя режимами возбуждения |
| v12 | Ogg Vorbis и Opus, стандартные контейнеры и статистика потока |

После v11 был создан потоковый декодер LPC2 для ATmega328P с PWM на D3, примерами чтения с SD и PROGMEM. Все соответствующие исходники находятся в `arduino/Lpc2AvrDecoder`.

Промежуточные HTML-файлы сохранены без переписывания в `archive/web`; они нужны для воспроизводимости экспериментов и сравнения алгоритмических изменений.
