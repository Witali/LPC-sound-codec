LFA‑3 v5: тональный и шумовой слои

Версия 5 дополняет палитровые синусоидальные дорожки отдельным шумовым слоем. Остаточная спектральная энергия после удаления областей вокруг тональных пиков распределяется по логарифмическим полосам. В файле уровни полос обновляются один раз на кадр, сжимаются маской изменений и малыми дельтами, а декодер восстанавливает их банком полосовых фильтров.

Как устроен шумовой слой

После поиска синусоид энкодер маскирует несколько FFT-бинов около каждого выбранного пика. Оставшаяся энергия суммируется в логарифмических полосах. Это улучшает шипящие согласные, дыхание, тарелки и другие широкополосные звуки. Короткие импульсы пока всё ещё передаются приблизительно: для них позднее можно добавить отдельный transient/ADPCM-слой.

Контейнер LFA‑3

LFA‑3 содержит два независимых потока. Первый — прежний LFA‑2 с палитрами частот. Второй — секция NOI1 с уровнями логарифмических шумовых полос.

Уровень каждой полосы квантуется в 5 бит: ноль означает выключенную полосу, остальные значения покрывают приблизительно −66…0 дБ. Каждый кадр передаёт маску изменившихся полос. Небольшая разность уровня помещается в один байт; крупное изменение использует escape и полный уровень.

При декодировании уровни линейно интерполируются между соседними кадрами, поэтому шум не включается ступенчато. Для каждой полосы используется двухполюсный полосовой фильтр, возбуждаемый детерминированным псевдослучайным генератором.
