# Архив веб-версий

Файлы в этой папке выгружены из опубликованной переписки и сохранены как исторические снимки. Актуальная версия находится в корне проекта: `audio_codec_lab_v12_vorbis_opus.html`.

Порядок развития:

1. `logarithmic_frequency_audio_codec.html` — LFA-1.
2. `logarithmic_frequency_audio_codec_v2.html` — устранение щелчков.
3. `logarithmic_frequency_audio_codec_v3_20ms.html` — сетка 20 мс.
4. `logarithmic_frequency_audio_codec_v4_palettes.html` — частотные палитры.
5. `logarithmic_frequency_audio_codec_v5_noise_layer.html` — шумовой слой.
6. `logarithmic_frequency_audio_codec_v6_talkie_compare.html` — LPC1 для сравнения.
7. `logarithmic_frequency_audio_codec_v7_normalized.html` — нормализация.
8. `logarithmic_frequency_audio_codec_v8_balanced_waveform.html` — баланс формы сигнала.
9. `logarithmic_frequency_audio_codec_v9_clear_lpc.html` — более ясный LPC.
10. `logarithmic_frequency_audio_codec_v10_grid_shift.html` — смещение сетки.
11. `audio_codec_lab_v11_lpc2_improved.html` — LPC2 Improved.
